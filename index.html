Business System & Modules

The system is divided into two major modules required for the SDC project.

🛡️

Admin Module

Admin monitors users and the overall student reporting system.

  • Admin Login
  • View Registered Users
  • Delete User Accounts
  • View Reports & Analytics
👥

User Module

The User Module supports Teacher, Student and Parent roles.

  • Teacher: manage academic report
  • Student: view own report
  • Parent: view student progress
  • Role-based dashboard redirection
